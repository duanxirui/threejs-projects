# Three.js 基础案例模板

这是一个使用 Three.js 和 Vite 制作的独立交互场景。创建正式案例后，请根据实际实现更新本页的介绍、功能、操作与素材说明；本文件面向体验者，不记录开发日志和待办事项。

## 项目介绍

基础模板提供一个可以旋转、缩放的 3D 场景，可用于开发独立的交互式案例。

## 功能与交互

- 通过鼠标或触摸拖动旋转视角，滚轮或双指捏合缩放。
- 使用页面按钮暂停动画、恢复视角。
- 具备响应式布局、独立静态资源与独立 Vite 构建配置。

## 技术实现

Three.js、WebGL、OrbitControls、Vite。初始场景的几何体由项目代码生成。

## 独立运行

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## 资源与授权

基础场景使用本地程序化几何体与项目内的 SVG 封面。加入第三方模型、图片或其他素材时，应在本节说明作者、来源和使用许可。
