# 像素奇想游乐园 · PIXEL PARK

一座漂浮在云端的微缩 3D 游乐园。整个园区由 Three.js 程序化生成，五种游乐设施持续运转，玩家可以自由环绕观察、选中设施、调整游园节奏，并切换复古像素画面与昼夜氛围。

[在线体验](https://duanxirui.github.io/threejs-projects/examples/miniature-amusement-park/) · [项目源码](https://github.com/duanxirui/threejs-projects/tree/main/examples/miniature-amusement-park)

## 场景与玩法

| 场景元素 | 体验内容 |
| --- | --- |
| 过山车 | 小型列车沿环岛木质轨道持续运行 |
| 摩天轮 | 12 个座舱随轮盘旋转并保持直立 |
| 旋转木马 | 彩色木马随转盘旋转，周期性上下起伏 |
| 海盗船 | 船体在支架间来回摆动 |
| 旋转茶杯 | 转盘与各茶杯以不同速度旋转 |
| 园区环境 | 分层浮空岛、商店、路灯、道路、树木、花朵、云朵及行走的游客 |

点击场景里的设施或底部对应入口，镜头会平滑移动到该设施；选择“全景”可返回游乐园整体视角。

## 交互方式

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 / 单指滑动 | 围绕游乐园旋转视角 |
| 滚轮 / 双指捏合 | 放大或缩小场景 |
| 点击设施 / 底部设施入口 | 聚焦指定设施 |
| 空格 | 暂停或继续场景动画 |
| N | 切换白天与夜晚 |
| R | 恢复全景视角 |
| H | 展开或收起设置面板 |

设置面板还提供运行速度（0.25×～2.5×）、游客数量（8～64 人）、像素渲染精度（25%～100%）、4×4 Bayer 有序抖动与有限色板开关。移动设备上面板默认收起；系统开启“减少动态效果”时，场景初始处于暂停状态。

## 视觉与技术

- **三维引擎：** Three.js、WebGL、OrbitControls。
- **场景建模：** 使用几何体、材质和动画算法搭建园区，不依赖外部 3D 模型或纹理服务。
- **动态游客：** 使用 `InstancedMesh` 合并重复几何体的绘制。
- **像素风格：** 低分辨率 `WebGLRenderTarget`、最近邻放大、颜色量化与 Bayer 有序抖动。
- **适配体验：** 响应式界面、昼夜灯光、平滑镜头聚焦及实时帧率显示。

## 独立运行

需要 Node.js 22.12 或更新版本。在本案例目录执行：

```bash
npm ci
npm run dev
```

生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`。本案例具有独立的依赖和资源，可单独复制与部署；更多安装细节见 [README](../README.md)。
